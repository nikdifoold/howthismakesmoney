Privacy Policy

Last updated: 6 November 2026

What this app is

"howthismakes" is a private tool used only by the owner of the YouTube channel How Does This Make Money (Flukeville) to upload the channel's own videos, set their thumbnails, titles, descriptions and schedules, and add them to the channel's playlists. It is not offered to anyone else.

What data it uses

When the channel owner signs in with Google, the app receives an access token for the owner's own YouTube channel, with the scopes it needs to upload and manage that channel's videos and playlists, and to read the channel's own video list. The token is stored only on the owner's computer. The app does not collect, store or share data about any other person, and it does not use the data for advertising.

YouTube API Services

This app uses the YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time on the Google security settings page.
